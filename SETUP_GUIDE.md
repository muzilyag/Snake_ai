# Как запустить
## 1. Требования
* **Python 3.10+**
* **CMake** (версии 3.15 или выше)
* **C++ компилятор** (MSVC, MinGW или GCC)
## 2. Настройка Python-окружения
Команды выполняются в корне репозитория
### Создание виртуального окружения
```bash
python -m venv venv
```
### Активация виртуального окружения
```bash
# Для Windows
.\venv\Scripts\activate
# Для Linux/macOS: 
source venv/bin/activate
```
### Установка зависимостей
```bash
pip install -r ./requirements.txt
```
## 3. Компиляция движка на C++
### Создание временной директории
```bash
mkdir build
```
```bash
cd build
```
### Кофигурация проекта
```bash
cmake ..
```
```bash
cmake --build . --config Release
```
### Копирование dll
```bash
copy .\Release\snake_cpp.pyd .\..
```
или
```bash
copy snake_cpp.pyd .\..
```
### Возвращение в корневую директорию проекта
```bash
cd ..
```
Должен появиться файл snake_cpp.pyd в корневой директории проекта
## 4. Запуск
```bash
python main.py
```
### Управление
* V - Включить/Выключить рендеринг игры (при выключенном рендеринге увеличивается скорость обучения)
* SPACE - Переключение скорости змеек
* G - Построить графики обучения
* S/L - Сохранить/Загрузить веса нейросетей
### Тепловая карта наград
Можно посмотреть тепловую карту распределения наград через веб-интерфейс
```bash
streamlit run src/utils/streamlit_visualizer.py
```
### Данные по обучению
Сохраняются в директорию stats в виде .csv файлов
